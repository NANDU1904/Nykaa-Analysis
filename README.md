# 🛍️ Nykaa Product Analysis Using Web Scraping & EDA

## 📌 Project Overview

This project focuses on analyzing product data collected from the **Nykaa website** using web scraping techniques. The collected data was cleaned, processed, and analyzed using Python to identify useful patterns and trends related to product categories, prices, discounts, ratings, and product performance.

The project demonstrates a complete **Data Analytics workflow**:

**Web Scraping → Data Collection → Data Cleaning → Exploratory Data Analysis → Data Visualization → Business Insights**


## 🎯 Objectives

- Collect product information from the Nykaa website using web scraping.
- Store the collected information in a structured dataset.
- Clean and preprocess the scraped data.
- Analyze product prices, discounts, ratings, and categories.
- Compare products across different categories.
- Create meaningful visualizations.
- Generate business insights from the analyzed data.


## 📊 Dataset

The dataset contains **140 Nykaa products** from the following categories:

- Beauty
- Healthcare
- Baby Care

### Dataset Columns

| Column | Description |
|---|---|
| Product Name | Name of the product |
| Original Price | Original price of the product |
| Selling Price | Selling price after discount |
| Discount | Discount percentage |
| Rating | Customer rating |
| Category | Product category |
| Savings | Amount saved after discount |

**Total Products:** 140  
**Total Columns:** 7  
**File Format:** CSV
